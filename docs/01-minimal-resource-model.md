# Минимальная ресурсная модель

Склад телеком-оборудования и расходных материалов.

Сейчас только два слоя:

1. **Справочники** — примитивные каталоги «ключ → значение». Запись может ссылаться на запись другого справочника. Ссылка называется **контекст**.
2. **Ресурсы** — основные сущности. Иерархия от абстракции к физическому экземпляру.

Процессы (приход, перемещение, выдача, списание, остатки) в эту модель не входят.

## Справочник

Справочник — именованный набор записей. Запись хранит ключ и значение. Никакой вложенной структуры у значения нет.

Если справочник объявил другой справочник своим контекстом, каждая его запись обязана указывать ровно одну запись того справочника.

Контекст — ссылка, не копия. Сменили значение у производителя — модель видит новое значение.

### Dictionary

| Поле | Смысл |
| --- | --- |
| id | идентификатор |
| code | стабильный код справочника |
| name | название |
| contextDictionaryId | справочник-контекст, либо пусто |

### DictionaryEntry

| Поле | Смысл |
| --- | --- |
| id | идентификатор |
| dictionaryId | справочник записи |
| key | ключ, уникален внутри справочника |
| value | значение, строка |
| contextEntryId | запись справочника-контекста, либо пусто |

### Правила

1. `contextEntryId` есть только когда у справочника задан `contextDictionaryId`. Тогда поле обязательно.
2. `contextEntryId` принадлежит именно справочнику-контексту, не любому.
3. Справочник не может быть контекстом сам себе. Цикл контекстов запрещён.
4. Один справочник может быть контекстом для нескольких других. У одного справочника контекст один.
5. Ключ уникален в пределах справочника.

### Стартовый набор

| code | name | контекст |
| --- | --- | --- |
| manufacturer | Производитель | — |
| model | Модель | manufacturer |
| uom | Единица измерения | — |

```
manufacturer
  huawei  → Huawei
  corning → Corning

model                         контекст
  ma5800     → MA5800         huawei
  sm-9-125   → SM 9/125       corning

uom
  pcs → шт
  m   → м
```

У модели `ma5800` нет поля «производитель». Есть ссылка на запись `huawei`.

## Ресурс

Оба уровня — ресурс. Отличаются местом в иерархии.

**Абстрактная единица** — спецификация. Общие атрибуты, которые есть у каждой физической единицы этого вида: форм-фактор, длина, длина волны.

**Серийная единица** — один физический экземпляр. Контекст и атрибуты не копирует. Читает их у абстрактной единицы. Своё добавляет серийным номером.

Глубина иерархии в минимуме — два уровня. Абстракция абстракции нет.

### Resource

| Поле | abstract | serial |
| --- | --- | --- |
| id | да | да |
| kind | `abstract` | `serial` |
| parentId | пусто | id абстрактной единицы |
| code | артикул, уникален | пусто |
| name | название | пусто |
| tracking | `serialized` или `bulk` | пусто |
| serialNumber | пусто | обязателен, уникален в паре с parentId |

`tracking` говорит, какая физика у этого вида:

- `serialized` — физический слой есть, это серийные дети. Оборудование.
- `bulk` — серийных детей нет. Кабель метражом, коннекторы упаковкой. Количество появится в процессах, не здесь.

### Контекст ресурса

Контекст ресурса — те же ссылки на записи справочников.

| Поле | Смысл |
| --- | --- |
| resourceId | ресурс |
| dictionaryId | справочник |
| entryId | запись этого справочника |

На абстрактной единице в минимуме две ссылки:

| справочник | правило |
| --- | --- |
| model | обязателен |
| uom | обязателен |

Производитель на ресурс не вешается. Он уже контекст модели. Цепочка: ресурс → модель → производитель.

На серийной единице своих контекстных ссылок нет. Эффективный контекст = контекст родителя.

Один ресурс — не больше одной ссылки на один справочник.

### Атрибут

Свободная пара ключ–значение. Это не справочник.

| Поле | Смысл |
| --- | --- |
| resourceId | ресурс |
| key | код атрибута |
| value | строка |

Атрибуты абстрактной единицы — общая спека. Пример: `wavelength_nm=1310`, `reach_km=10`, `length_m=3`.

Серийный номер — поле сущности, не атрибут. Он входит в идентичность экземпляра.

Свои атрибуты у серийной единицы в минимуме не задаются. Ключ серийной единицы не может повторить ключ родителя: спека не переопределяется экземпляром.

Эффективные атрибуты серийной единицы = атрибуты абстрактного родителя.

Значения не копируются. Правка атрибута абстрактной единицы видна всем её серийным детям.

### Правила иерархии

1. У `abstract` нет родителя.
2. У `serial` родитель ровно один, и это `abstract`.
3. Серийный ребёнок разрешён только если у родителя `tracking = serialized`.
4. У `bulk` серийных детей нет.
5. Артикул, название, единица измерения и модель живут на абстрактной единице.
6. Абстрактную единицу нельзя удалить, пока есть серийные дети.

## Примеры

Оборудование.

```
abstract
  code:       SFP-10G-LR
  name:       Модуль SFP+ 10G LR
  tracking:   serialized
  context:    model = sfp-10g-lr-hw → manufacturer = huawei
              uom   = pcs
  attributes: form_factor=SFP+  rate=10G  wavelength_nm=1310  reach_km=10

serial
  parent:       SFP-10G-LR
  serialNumber: HW192837465
  context:      тот же, что у родителя
  attributes:   те же, что у родителя
```

Расходник без серии.

```
abstract
  code:       PATCH-SM-LC-LC-3M
  name:       Патчкорд SM LC-LC 3м
  tracking:   bulk
  context:    model = patch-sm-lc-lc → manufacturer = corning
              uom   = pcs
  attributes: length_m=3  fiber=SM  connector=LC-LC

serial:       нет
```

Кабель метражом — тот же `bulk`, `uom = m`.

## Что модель уже умеет

- Завести производителя и модель, не дублируя имя производителя.
- Описать вид оборудования или расходника: артикул, модель, единица измерения, спека.
- Завести физический экземпляр оборудования с серийным номером, который наследует спеку и контекст вида.
- Отличить серийный учёт от количественного, не вводя остатки.

## Чего в модели нет

- Склад, зона, ячейка.
- Количество, партия, резерв, документ.
- Статус экземпляра: на складе, выдан, установлен, списан.
- Пользователи и права.
- Схема атрибутов отдельным справочником. Ключи атрибутов пока свободные строки.
- Третий уровень ресурса. Кандидат позже: партия. Наследует абстрактную единицу с `tracking = bulk`, добавляет номер партии. Это уже сосед процессов.

## Инварианты

1. Контекст записи справочника принадлежит справочнику, который объявлен контекстом.
2. Контекст ресурса принадлежит заявленному справочнику.
3. У абстрактной единицы есть модель и единица измерения.
4. Производитель читается только через модель.
5. Серийная единица — ребёнок одной абстрактной единицы с `tracking = serialized`.
6. Эффективные контекст и атрибуты серийной единицы равны родительским.
7. Пара `(parentId, serialNumber)` уникальна.
