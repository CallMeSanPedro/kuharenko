# kuharenko

Эталон модернизации UI склада и инструкция для ChatGPT.

## Для ChatGPT

Загрузите в чат два файла:

1. [`CHATGPT.md`](CHATGPT.md) — правила стиля, компоновка, токены, ограничения WPF
2. [`docs/mockups/warehouse-ui-mockup.png`](docs/mockups/warehouse-ui-mockup.png) — целевой макет

Затем приложите одну View склада, её ViewModel / code-behind, общие стили и `.csproj`.

## Что в макете

- шапка и пункты меню на месте
- вкладки `Складские остатки` / `Список документов` / `Параметры склада` сохранены
- фильтры, колонки таблицы и нижние вкладки объекта не выкидываются
- внутри экрана master-detail: таблица + карточка выбранного оборудования + детали снизу
